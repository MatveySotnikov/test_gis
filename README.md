# ColorChanger Plugin for QGIS

Плагин **ColorChanger** предназначен для изменения значения атрибута `color` у объектов векторных слоёв QGIS.

---

# Функциональность

- Поддержка точечных, линейных и площадных слоёв
- Выбор слоя из проекта QGIS
- Выбор объекта слоя
- Выбор нового цвета через `QColorDialog`
- Изменение значения поля `color`
- Автоматическое обновление отображения слоя

---

# Требования к слоям

Слой должен содержать поле:

- `color` — строковое поле для хранения цвета

Пример значений:

- `#ff0000`
- `#00ff00`
- `#0000ff`

---

# Настройка стилей QGIS

Для корректной работы необходимо настроить символику слоя через привязку цвета к полю `color`.

---

# Установка

1. Скопируйте папку плагина в директорию плагинов QGIS:

```text
C:/Users/USERNAME/AppData/Roaming/QGIS/QGIS3/profiles/default/python/plugins
```

2. Запустите QGIS
3. Откройте Менеджер плагинов
4. Включите плагин **ColorChanger**

---

# Использование

1. Добавьте слой в проект QGIS
2. Убедитесь, что слой содержит поле `color`
3. Настройте стиль слоя через поле `color`
4. Запустите плагин
5. Выберите слой и объект
6. Выберите новый цвет
7. Цвет объекта будет обновлён автоматически

---

# Структура данных из ТЗ

## Buildings (Polygon)

## Trees (Point)

- `height`
- `color`

## Roads (Line)

- `fid`
- `type`
- `color`
